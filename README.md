# CG_work0
第一次计算机图形学作业
图形学实验报告：项目架构、代码逻辑及实现功能介绍

**一、项目架构**

本次实验项目名称为CG-Lab，严格按照src布局规范整理目录，实现代码分层解耦，具体目录结构如下：

CG-Lab/

├── .gitignore

├── README.md
├── src/
│   └── Work0/
│       ├── __init__.py
│       ├── config.py
│       ├── physics.py
│       └── main.py
└── .venv/

项目分为三层，分别是参数配置层（config.py）、底层计算层（physics.py）、前端视图层（main.py），各层功能独立，方便修改和维护。

二、代码逻辑

1.  config.py：集中定义窗口大小、粒子数量、物理参数等所有可配置信息，避免代码硬编码。

2.  physics.py：基于Taichi框架，初始化GPU后端，实现粒子初始化、万有引力计算、粒子速度和位置更新的并行逻辑。

3.  main.py：创建可视化窗口，调用physics.py中的计算逻辑，实现粒子渲染和GUI参数交互，完成整个仿真流程。

三、实现功能

1. 搭建标准化图形学开发环境，使用uv工具链管理虚拟环境，避免依赖冲突。

2. 通过Taichi调用GPU并行计算，实现10000个粒子的万有引力实时仿真。

3. 实现粒子窗口边界反弹，支持GUI调节引力常数，动态观察粒子运动变化。

4. 完成代码Git版本控制，上传项目至GitHub/Gitee，编写说明文档。
